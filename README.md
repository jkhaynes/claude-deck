# Claude Deck

A free Stream Deck plugin for Claude Code. Switch your Stream Deck to its "Claude" profile to see each running Claude Code session at a glance (working, needs approval, waiting for you, done), and allow or deny permission requests with one tap. It's built on Claude Code's hooks. If the plugin isn't running, Claude simply shows its normal prompt.

Unofficial; not affiliated with Anthropic or Elgato.

## Status
Early design. See [docs/prd.md](docs/prd.md) for what's planned and [docs/state.md](docs/state.md) for where things stand.

## Prerequisites
- Windows 10/11 (macOS untested)
- Stream Deck app 6.9 or later (developed on a Stream Deck Neo)
- Node.js 20 or later
- Claude Code installed natively (not in WSL)
